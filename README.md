# Webrecon 🕵️‍♂️

A lightweight, command-line web reconnaissance and admin path finder tool built in Python. Designed for fast enumeration of common web directories and security auditing.

## Installation

```bash
# Clone the repository
git clone https://github.com/makson2006/webreconLinux webrecon
cd webrecon

# Make executable and move to path
chmod +x webrecon
sudo mv webrecon /usr/local/bin/webrecon
